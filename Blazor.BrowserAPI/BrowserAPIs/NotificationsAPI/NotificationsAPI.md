# NotificationsAPI

The Notifications API allows web pages to control the display of system notifications to the end user.


<br><br />
## Example

```csharp
public sealed partial class ExampleComponent : ComponentBase {
    [Inject]
    public required INotificationsAPI NotificationsAPI { private get; init; }

    [Inject]
    public required IServiceWorkerContainer ServiceWorkerContainer { private get; init; }


    public async Task InitNotifications() {
        string permission = await NotificationsAPI.RequestPermission();
        if (permission != "granted")
            return;

        await ServiceWorkerContainer.Register("ServiceWorker.js");
        IServiceWorkerRegistration serviceWorkerRegistration = await ServiceWorkerContainer.Ready; // waiting until service worker is in state "ready"

        await serviceWorkerRegistration.ShowNotification("Success", body: "Persistent notification received");
    }
}
```

### Notification

The Notification interface of the Notifications API is used to configure and display desktop notifications to the user.

These notifications' appearance and specific functionality vary across platforms but generally they provide a way to asynchronously provide information to the user.

Objects of this class must disposed manually, so do not forget to call *DisposeAsync* when you are done with it.
